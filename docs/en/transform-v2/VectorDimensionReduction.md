# VectorDimensionReduction

> Vector dimension reduction

## Description

The `VectorDimensionReduction` transform plugin is used to perform dimensionality reduction on specified vector fields. This is very useful in machine learning and vector database scenarios to reduce storage requirements, speed up retrieval, and potentially filter out noise.

## Name

`VectorDimensionReduction`

## Examples

Suppose our source data contains a 1024-dimensional vector named `feature`, and we want to reduce its dimension to 128 using sparse random projection.

```hocon
env {
  job.mode = "BATCH"
}

source {
  FakeSource {
    row.num = 100
    schema = {
      columns = [
        {
          name = id
          type = int
        },
        {
          name = feature
          type = "array<float>"
          options = {
            length = 1024
          }
        }
      ]
    }
  }
}

transform {
  VectorDimensionReduction {
    vector_fields = ["feature"]
    source_dimension = 1024
    target_dimension = 128
    reduction_method = "SPARSE_RANDOM_PROJECTION"
  }
}

sink {
  Assert {
    rules = {
      field_rules = [
        {
          field_name = id
          field_type = int
        },
        {
          field_name = feature
          field_type = "float_vector"
        }
      ]
    }
  }
}
```

In this example, the `Assert` Sink will verify that the output `feature` field has the type `float_vector`. Through the internal schema transformation of the `VectorDimensionReduction` plugin, downstream components will automatically be aware that the dimension of the `feature` field has been changed to 128.
