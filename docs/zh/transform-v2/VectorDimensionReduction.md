# VectorDimensionReduction

> Vector dimension reduction

## 描述

`VectorDimensionReduction` 转换插件用于对指定的向量（Vector）字段进行降维操作。这在机器学习和向量数据库场景中非常有用，可以减少存储需求、加快检索速度并可能滤除噪声。

## 名称

`VectorDimensionReduction`

## 示例

假设我们的源数据包含一个名为 `feature` 的 1024 维向量，我们希望使用稀疏随机投影将其降维到 128 维。

```hocon
env {
  job.mode = "BATCH"
}

source {
  FakeSource {
    row.num = 100
    schema = {
      columns = [
        {
          name = id
          type = int
        },
        {
          name = feature
          type = "array<float>"
          options = {
            length = 1024
          }
        }
      ]
    }
  }
}

transform {
  VectorDimensionReduction {
    vector_fields = ["feature"]
    source_dimension = 1024
    target_dimension = 128
    reduction_method = "SPARSE_RANDOM_PROJECTION"
  }
}

sink {
  Assert {
    rules = {
      field_rules = [
        {
          field_name = id
          field_type = int
        },
        {
          field_name = feature
          field_type = "float_vector"
        }
      ]
    }
  }
}
```

在这个例子中，`Assert` Sink 会验证输出的 `feature` 字段类型是否为 `float_vector`。通过 `VectorDimensionReduction` 插件的内部 Schema 转换，下游组件会自动得知 `feature` 字段的维度已经变为了 128。
